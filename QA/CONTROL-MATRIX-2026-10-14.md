Continuous knobs use SDK CAnimKnob drag/wheel/key behavior. Module toggles use SDK COnOffButton press/release. Selectors dispatch one beginEdit/valueChanged/endEdit gesture to the editor. In the pinned SDK, CControl's event listener handles Ctrl-left reset BEFORE custom mouse dispatch, and VST3Editor assigns the actual default value; the absence of a custom Ctrl branch is not by itself a defect. No native Windows event claim is made from this inspection.
