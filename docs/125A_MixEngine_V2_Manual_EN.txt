125A MixEngine V2
User Manual - Windows x64 VST3
Version 2.0.0

OVERVIEW
125A MixEngine V2 is a coloration, summing and mix-finishing processor with two editions built from the same DSP core:
- 125A MixEngine V2: PreSonus Studio One Mix FX edition with real adjacent-channel crosstalk.
- 125A MixEngine V2 Channel: standard VST3 insert edition for tracks, buses and hosts without the PreSonus Mix FX API.

SIGNAL FLOW
INPUT -> CONSOLE -> TUBE -> TAPE -> GLUE -> VINYL -> STEREO -> OUTPUT
The order is fixed. Modules may be used simultaneously.

V2 - WHAT IS NEW?
- Sample-offset accurate automation for standard VST3 and Mix FX.
- 0 percent is a true neutral point for intensity controls.
- Continuous monotonic control laws without hard jumps; 20-50 percent is the normal musical working range, while 75-100 percent is intentionally strong/creative.
- Tube Voice and Tape Speed morph continuously between their three characters internally.
- Tape combines the v1.1 compression envelope with additional magnetic/hysteresis memory.
- Glue uses program-dependent release and more musical transient handling.
- Vinyl Color and Wear are separate axes: material/body versus HF/stylus wear.
- Console Classic/Vintage/Modern are more clearly differentiated; Vintage includes bounded decaying transformer memory.
- Scoped FTZ/DAZ denormal protection is active only inside audio callbacks and restores the host floating-point state afterward.
- 32-/64-bit audio and 44.1, 48, 96 and 192 kHz operation were tested.

INPUT / LEVEL MATCH
INPUT GAIN adjusts the level before coloration. LEVEL MATCH compensates parameter-dependent level changes; it is not an adaptive loudness normalizer. With Level Match enabled, the linear component of Input Gain is compensated at the output while the altered drive into nonlinear stages remains effective.

REFERENCE LEVEL
0 VU can reference -18, -14 or -10 dBFS. 0 VU is a working reference, not a level that music should constantly hit.

CONSOLE
MODE: Clean, Classic, Vintage, Modern.
DRIVE: controls console coloration/density. 0 percent is neutral.
CROSSTALK: Mix FX edition only; couples real adjacent Mix FX channels and is not an L/R stereo blend.
NOISE: independent console noise.

TUBE
VOICE: Soft, Balanced, Hot.
AMOUNT: tube coloration intensity. 0 percent is neutral.
Voice selection is internally morphed smoothly to avoid hard DSP jumps during switching or automation.

TAPE
AMOUNT: tape character and saturation.
SPEED: 7.5 / 15 / 30 ips with continuous internal morphing.
STABILITY: transport stability; lower values create stronger movement.
HISS: independent tape noise.
V2 retains the program-dependent tape compression from the Final v1.1 foundation and adds state-dependent magnetization/hysteresis.

GLUE
AMOUNT: strength of the bus-style dynamic cohesion.
RESPONSE: shifts attack/release character between smoother and more direct behavior.
The V2 model is program dependent and designed for bus/mix use.

VINYL
COLOR: material/body and asymmetric harmonic coloration.
WEAR: HF loss and stylus/compliance character.
SURFACE: independent surface noise/click amount.
Color and Wear are deliberately separate sonic axes in V2.

STEREO
DEPTH: changes perceived depth.
WIDTH: 0-200 percent stereo width.
LOW MONO: progressively monoizes the low-frequency region around the fixed 120 Hz area.

QUALITY
Eco = 1x, Normal = 2x, High = 4x. Higher quality reduces aliasing in nonlinear stages at higher CPU cost. Reported host latency remains fixed at 21 samples.

AUTOMATION
V2 applies VST3 automation points at their sample offsets inside the audio block. This applies to both the standard Channel edition and the Mix FX path. Character parameters are additionally smoothed to avoid hard transitions.

INSTALLATION
1. Close the DAW.
2. Copy the desired .vst3 bundle to C:\Program Files\Common Files\VST3.
3. Start the DAW and rescan VST3 plugins if required.

WHICH EDITION?
Studio One Mix FX slot: 125A MixEngine V2.
Normal track/bus/other VST3 host: 125A MixEngine V2 Channel.
Both editions may be installed side by side.

PRACTICAL STARTING POINTS
Start around 20-50 percent Amount/Drive. 50-75 percent is clearly stronger. 75-100 percent is intentionally creative and may be excessive. Judge settings in the context of the mix.

VALIDATION
The V2 build is covered by tests for zero neutrality, range continuity, oversampling/aliasing, fixed latency, phase/mono behavior, Level Match, Channel/Mix-FX parity, sample-accurate automation, quality switching, Tape/Console memory, Glue transients, Vinyl axis separation, denormal hardening and multiple sample rates/sample formats. The Channel edition passes the Steinberg VST3 Validator.
